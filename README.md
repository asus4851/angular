# ClipFactory 🎬

**Фабрика контенту**: автоматично перетворює відео з YouTube-каналів на короткі вертикальні кліпи (Reels/Shorts/TikTok) і публікує їх у ваші акаунти в соцмережах.

```
YouTube-канали → субтитри → AI-аналіз (Claude) → нарізка (ffmpeg) →
рілс-формат 9:16 + анімовані субтитри → автопостинг (Shorts / Reels / TikTok)
```

## Як це працює

1. **Ви додаєте YouTube-канали** — джерела контенту.
2. **Ви додаєте свої акаунти** соцмереж (YouTube Shorts, Instagram Reels, TikTok, або просто локальний експорт).
3. **Ви створюєте маршрути**: «відео з каналу X → публікувати в акаунт Y».
4. Далі все автоматично:
   - планувальник періодично перевіряє канали на нові відео;
   - для кожного відео завантажуються субтитри;
   - Claude аналізує транскрипт і знаходить потенційно вірусні моменти (з таймкодами, заголовком, хуком, хештегами та оцінкою віральності);
   - ffmpeg вирізає фрагмент, конвертує у вертикальний формат 1080×1920 (кроп або розмитий фон) і накладає стилізовані субтитри;
   - готовий кліп публікується в усі акаунти, призначені маршрутами каналу.
5. Опційно — **режим модерації**: кліпи чекають вашого підтвердження в веб-дашборді перед публікацією.

## Швидкий старт

Вимоги: **Python 3.11+**, **ffmpeg** (`apt install ffmpeg` / `brew install ffmpeg`).

```bash
# 1. Встановлення
uv venv && source .venv/bin/activate
uv pip install -e .

# 2. Конфігурація
cp .env.example .env
# впишіть ANTHROPIC_API_KEY (без ключа працює евристичний аналізатор)

# 3. Ініціалізація БД
clipfactory init

# 4. Демо без інтернету й ключів: синтетичне відео проходить весь конвеєр
clipfactory demo

# 5. Запуск (API + дашборд + воркер + планувальник в одному процесі)
clipfactory run
# Дашборд: http://localhost:8000
```

## Приклад використання через CLI

```bash
# Додати канал-джерело
clipfactory channel add "https://www.youtube.com/@SomeChannel" --auto-approve

# Додати акаунт призначення (local = експорт у папку, без креденшелів)
clipfactory account add --platform local --name "мій-експорт"

# Створити маршрут: канал → акаунт
clipfactory route add --channel 1 --account 1

# Разово перевірити канали на нові відео
clipfactory poll

# Подивитись стан конвеєра
clipfactory status
```

Те саме доступно у веб-дашборді: канали, акаунти, маршрути, стрічка кандидатів у кліпи з прев'ю, підтвердження/відхилення, історія публікацій.

## Платформи публікації

| Платформа | Механізм | Що потрібно |
|---|---|---|
| `local` | експорт mp4 + metadata.json у папку `exports/` | нічого — працює одразу |
| `youtube` | YouTube Data API v3 (Shorts) | OAuth client + refresh token |
| `instagram` | Instagram Graph API (Reels) | Business-акаунт, токен, публічний `PUBLIC_BASE_URL` |
| `tiktok` | TikTok Content Posting API | Зареєстрований додаток, access token |

Деталі підключення кожної платформи: [docs/PUBLISHERS.md](docs/PUBLISHERS.md).

## Важливо

- Використовуйте лише контент, на який маєте права (власні канали, дозвіл автора, ліцензія). Реаплоад чужого контенту порушує правила платформ та авторські права.
- Креденшели акаунтів шифруються у БД (Fernet, ключ `SECRET_KEY` з `.env`).
